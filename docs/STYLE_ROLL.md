# Roll 串：抽取与保存

Roll 串用于从现有画师库抽取组合、有限出图并直接保存喜欢的配方。产品边界见[产品宪法](../VIBER_INTENT.md)，当前操作见 [README](../README.md)，维护约定见[产品决策记录](./PRODUCT_DECISIONS.md)。

## 当前工作流

| 环节 | 本项目行为 |
| --- | --- |
| 一轮出图 | 设置每串画师数与本轮张数，一次发起有限任务、逐张生成并保存；付费先确认整轮总费用。出图后留在图库，直接挑选保存 |
| 画师来源 | 使用现有画师库的完整 Tag 词库，无需另建名单或预先收藏；缺样张的画师也可抽取。搜索／手填用于可选的锁定、排除或补充 |
| 创作控制 | 设置画师数量和权重范围；锁定必选画师及权重，排除暂不使用的画师，过滤重复组合 |
| 公共配置 | 每条记录保存完整提示词、角色、模型、尺寸、参数和固定 Seed。有候选后公共配置冻结，变更条件另建记录 |
| 保留偏好 | 已成功保存为风格串的组合指导当前记录后续抽取，每四套保留一套全新随机。继承约三分之二可用非锁定画师并小幅调权重，从完整词库补齐；归档项、旧验证副本和无可用画师的组合不作为偏好来源 |
| 手动调权 | 详情「更多操作 → 手动调整权重」保存新候选配方，原候选与图片不变，不自动出图；由用户主动生成或送往实验室 |
| 浏览与管理 | 复用工坊工具栏、卡片、图片布局和原位多选；按画师 Tag、编号、状态和轮次筛选，按新旧排序。单项／批量保存、丢弃和恢复，记录支持重命名、新建、导出与可恢复收起 |
| 继续未完成任务 | 「补齐剩余」只提交当前未关闭普通批次的未生成原配方；旧轮缺图可选中后主动生成。旧验证副本不参与补图，旧投票绑定原图缺失不能重画替代 |
| 资产闭环 | 图片进入正常历史，共用收藏与图片分享；满意候选保存为完整风格串，或带完整配置送往实验室 |

用户已明确取消画风对比、两两投票、Elo 排名、进化评选、自动权重测试及换 Seed 验证；相关界面、快捷键和执行算法已移除，不保留可选入口。普通 Roll 的保存偏好抽取独立工作，不依赖评分或评图模型。

## 数据与恢复

- 资料沿用 `/api/style-roll` 和既有私人 `settings`，按用户及记录 ID 隔离；不新增表、迁移文件或更改存储定位键。原有工坊备份覆盖记录与原图。
- 画师目录沿用完整分片读取与缓存，不受页面加载数量或手填条目上限影响。记录只保存锁定／排除等覆盖项与实际候选，不复制整份词库。目录失败明确提示并可重试，旧候选仍可查看、手动调权和生成原配方。
- 旧候选来源、轮次、投票、谱系及原图绑定继续通过原校验读取和保存，不清理、不迁移，也不重新计算排名。旧验证副本留在历史和配置中，不混入日常图库或保存偏好，不继续执行旧验证任务。
- 候选与记录使用可恢复状态收起，不物理删除设置、历史或风格串。保存携带版本号，冲突明确提示重新加载，不静默覆盖；坏存档报错，不以空记录覆盖。
- 生成复用既有有限多配方后台任务，每项保留提示词、Seed 与历史来源；沿用同 Key 互斥、间隔、暂停、后台保存和费用上涨确认。失败／取消不重新抽串或自动重试，已有成果和原配方保留。
- 历史按记录来源 ID 与候选模块 ID 关联。旧投票涉及的候选继续绑定原历史 ID，缺失时不接受后来图片冒充；固定 Seed 不受实验室的强制随机偏好影响。历史读取失败不当作尚未生成，避免重复消费。
- 切页不取消已提交任务；关闭／刷新行为遵循已有任务服务，不建立重启自动续跑任务。切 Key 不授权旧任务，后台暂停、费用补充授权与取消均由用户主动操作。
- 「存为风格串」保存实际生成参数并持久保存独立封面，后续编辑不反写记录。JSON 导出只含记录配置及保留的旧投票，不含图片、Key 或账号设置，不能代替完整备份。

## 维护入口

- `services/styleRoll.ts`：资料校验、画师规则、普通抽取、保存偏好与手动变体。
- `services/styleRollWorkflow.ts`：普通有限批次与旧验证副本识别。
- `services/styleRollApi.ts`、`styleRollGeneration.ts`：记录、历史及既有后台生成的接缝。
- `services/styleRollWorkspace.ts`：图库范围、搜索排序与补图资格。
- `components/StyleRollPage.tsx`、`components/roll/`：图库、详情、记录管理、原位多选与配置。
- `worker/routes/styleRollRoutes.ts`：私人资料验证与并发版本检查。
- `tests/services/styleRoll*.test.ts`、`tests/components/StyleRoll*.test.tsx`、`tests/worker/styleRollRoutes.test.ts`：合成资料回归，含旧记录兼容与原图保护；导航和多语另有对应集成覆盖。

工程测试不消费真实额度，不读取私人资料作为夹具。
