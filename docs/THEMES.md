# 制作和分享设计主题

在「全局设置 → 外观与画廊」调整强调色、密度、圆角、材质、字号、动效及图库效果；展开「自定义明暗配色」，可分别编辑浅色和深色版本。修改实时预览，「另存当前主题」保存为新主题；已有自定义主题修改后可「保存修改」覆盖该主题，内置默认始终锁定。

主题卡片展示已保存的外观。出现「当前外观已修改」时，可保存或「导出当前外观」；卡片导出与「导出全部」始终导出已保存的内容。重置外观保留主题库、生图偏好和实验室布局；删除当前主题会真正恢复默认外观。

## 从示例开始

下载[暖纸示例](../public/themes/warm-paper.json)，在主题区点「导入」选择文件，也可直接拖入主题区。示例同时提供米白浅色版和暖棕深色版，可在界面调整后另存、导出并分享。导入会生成新 ID，重名自动加编号，不覆盖已有主题；内置默认导出后可作为普通主题导入。

也可以用文本编辑器修改示例。当前文件格式为：

```json
{
  "version": 2,
  "presets": [
    {
      "name": "我的主题",
      "accentColor": "#b96e2b",
      "themeMode": "system",
      "palette": {
        "light": { "canvas": "#f5ecdc", "panel": "#fffbf3", "text": "#3d3025" },
        "dark": { "canvas": "#211c19", "panel": "#352c25", "text": "#f5e8d3" }
      }
    }
  ]
}
```

## 字段

`name` 必填，最多保留 30 个字符；其他字段缺省时使用默认值。颜色必须是六位十六进制形式，如 `#fff4dd`，支持大小写。文件导出不携带生图、密钥、语言或图库列数设置。

| 字段 | 允许值 | 默认值 |
| --- | --- | --- |
| `accentColor` | 六位十六进制颜色 | `#0ea5e9` |
| `themeMode` | `light`、`dark`、`system` | `system` |
| `density` | `comfortable`、`standard`、`compact` | `standard` |
| `corners` | `soft`、`standard`、`sharp` | `standard` |
| `surfaces` | `solid`、`translucent` | `solid` |
| `motion` | `full`、`reduced`、`off` | `full` |
| `fontScale` | `small`、`standard`、`large` | `standard` |
| `galleryFrostedCaption` | 布尔值 | `true` |
| `galleryHoverFloat` | 布尔值 | `true` |
| `gallerySelectionFocus` | 布尔值 | `true` |
| `palette` | 分别配置 `light`／`dark`；字段见下表 | 原有默认配色 |

| 配色字段 | 控制范围 |
| --- | --- |
| `canvas` | 工作区背景 |
| `sidebar` | 侧栏背景 |
| `toolbar` | 工具栏和导航背景 |
| `panel` | 弹层、面板和中性控件的表面基色 |
| `text` | 正文及主要文字 |
| `mutedText` | 次要文字 |
| `border` | 面板边框 |

明暗版本和各个颜色均可只填写需要改变的部分，其余保持对应版本的默认值。输入框、卡片等已有中性色阶从面板与文字颜色派生，透光材质与阴影也跟随配色；强调色上的文字／图标会选择可辨认的前景色。正文和次要文字仍尊重作者填写的颜色，编辑器会提示正文与面板对比度过低的组合。

## 兼容与范围

支持版本 1、版本 2，以及旧版的单主题对象／主题数组。新导出统一使用版本 2；未知版本、错误选项、错误颜色和不支持的字段会报错，整份文件不会部分导入。旧文件缺少新字段时继续使用默认值。

主题基于现有布局和语义颜色制作，不执行 CSS、JavaScript，不加载远程字体、图片或代码。保存、危险与来源颜色、作品像素、安全模式和触控区域保留原有含义。电脑主界面、手机界面使用同一套主题，Windows 收集小窗同步明暗版本、面板、文字、边框与强调色。

主题和当前修改按本端浏览器保存。分享、换设备或清除浏览器资料前，请导出需要保留的主题；各设备可独立选择主题。
